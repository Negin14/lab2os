# Частина 5. Читання файлу через mmap

Тема: відображення файлів у пам'ять. Інформація: `man 2 mmap`, OSTEP [21. Beyond Physical Memory: Mechanisms](https://pages.cs.wisc.edu/~remzi/OSTEP/vm-beyondphys.pdf), [23. Complete Virtual Memory Systems](https://pages.cs.wisc.edu/~remzi/OSTEP/vm-complete.pdf) (розділ про Linux).

## Мета

Побачити файл як масив байтів у адресному просторі і зрозуміти, звідки беруться його сторінки.

## Дано

`mmap_read.c`: готова програма, кожен її крок пояснено в коментарях. Писати нічого не потрібно, потрібно зрозуміти і виміряти.

## Завдання

1. Створіть тестовий файл у домашньому каталозі. Не в `/tmp`: там часто tmpfs. І не в каталозі лабораторної: у Vagrant це спільна папка з вашим комп'ютером. В обох випадках сторінки файлу поводяться інакше.

   ```sh
   seq 1 1000000 > ~/numbers.txt
   ls -l ~/numbers.txt
   wc -l ~/numbers.txt
   ```

2. Запустіть і перевірте, що кількість рядків збігається з `wc -l`:

   ```sh
   ./part5-mmap/mmap_read ~/numbers.txt
   ```

3. Порівняйте кількість faults із кількістю сторінок файлу та зі своїми вимірами для анонімної пам'яті в частині 4.

4. Витісніть файл із page cache і запустіть знову:

   ```sh
   sync && echo 3 | sudo tee /proc/sys/vm/drop_caches
   ./part5-mmap/mmap_read ~/numbers.txt
   ./part5-mmap/mmap_read ~/numbers.txt
   ```

   Зазвичай після `drop_caches` з'являються major faults, але їх значно менше, ніж сторінок файлу: readahead читає наперед, а fault-around може відобразити кілька вже наявних у кеші сторінок за один fault. Точні числа залежать від ядра, файлової системи й стану кешу; один major fault — можливий результат, а не вимога. Наведіть свої числа й поясніть різницю між запусками, зокрема чому повторний запуск зазвичай обходиться без major faults.

5. Роздивіться рядок maps, який друкує програма: права, зміщення, inode і шлях. Порівняйте з рядками анонімних відображень із частини 1.

## Запитання для самоперевірки й захисту

- Два процеси відобразили той самий файл з `MAP_PRIVATE`. Скільки копій його сторінок у RAM? Що зміниться, якщо один із них запише в `data[0]`?
- А якщо відображення `MAP_SHARED`: що побачить другий процес і що станеться з файлом?
